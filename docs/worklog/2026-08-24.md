### 설계 판단
- 대표품목 변동률은 **품종별 전일대비의 중앙값**. 품종마다 단위(4kg상자/10kg망대)가 달라 절대가 평균은 무의미
- `PAV_RATE`의 전일가가 당일 평균가와 같으면 '전일 자료 없음' 기본값 → 변동률 계산에서 제외. 안 걸러내면 중앙값이 0%로 눌림
- 급등락 집계를 **반입량 상위 30품목**으로 제한. 3톤짜리 품목의 +124%는 노이즈
- 산포도는 사용자 요청으로 제거하고 다이버징 막대로 대체
- 수집 시각은 과일 확정 기준 **14:00 단일**로 통일

## 6. 사용자 피드백 반영 (수정)

### 버그 — 급등락 목록에 청과가 통째로 빠짐
`allItems()` 가 부문별로 이어붙은 배열을 반환하는데, 여기에 `slice(0, 30)` 을 걸었다.
채소가 61품목이라 상위 30개가 **전부 채소**가 되어 청과가 하나도 들어가지 못했다.

- 원인: 전역 정렬 없이 concat 순서에 의존
- 수정: 급등락 후보를 **부문별 반입량 상위 20품목**의 합집합으로 구성
- 결과: 청과 6건(멜론 +51.5%, 수박 +44.8%, 오이 +37.2%, 무화과 -35.5%, 호박 +28.9%, 참외 +15.5%) / 채소 4건
- 표에 부문 배지를 추가해 어느 부문인지 바로 보이게 함

전역 반입량 정렬로 고칠 수도 있었지만(그래도 청과 12/30), 물량이 큰 채소가 계절에 따라
자리를 다 차지할 수 있어 부문별로 뽑는 쪽이 안전하다.

### 자유 내비게이션
브레드크럼(경로 표시)을 걷어내고 **상단 고정 내비게이션 바**로 교체했다.
브레드크럼은 지나온 경로만 보여줄 뿐, 옆으로 건너뛰는 이동을 못 한다.

- `전체 · 채소 · 청과` 칩이 **모든 단계에서 항상 보이고 항상 눌린다**
- 1단계 → 부문 칩 클릭으로 2단계 직행
- 2단계 → 같은 레벨에서 청과 ↔ 채소 즉시 전환
- 3단계 → 부문 칩을 누르면 그 부문 목록으로 바로 점프
- 선택된 품목은 칩으로 표시하고 `✕` 로 해제
- 3단계 **진입**은 요청대로 품목 행 클릭 방식 유지 (품목이 많아 드롭다운이 부적합)
