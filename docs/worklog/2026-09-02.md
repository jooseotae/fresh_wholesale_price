# 2026-09-02 · shadcn/ui 디자인 시스템 적용

## 배경
대시보드 UI를 [ui.shadcn.com](https://ui.shadcn.com) 스타일로 통일하자는 요청.

## 판단: 라이브러리가 아니라 "디자인 시스템"을 이식
shadcn/ui는 React + Tailwind + Radix 조합이다. 이 프로젝트는

- 빌드 스텝 없음 (Python이 `template.html`에 데이터를 주입해 정적 HTML 생성)
- 런타임 의존성 0 (표준 라이브러리만)
- Vercel 정적 호스팅

이라서 shadcn 컴포넌트를 그대로 가져올 수 없다. 대신 **디자인 토큰과 컴포넌트
스타일 규칙만 순수 CSS로 옮겼다.** 결과적으로 보이는 건 shadcn이지만
의존성은 여전히 0이고, 수집·빌드 파이프라인은 한 줄도 안 바뀌었다.

## 적용한 것

| 영역 | shadcn 규칙 | 반영 |
|---|---|---|
| 팔레트 | neutral scale | `#fafafa`~`#0a0a0a` 9단계, 다크모드 대칭 |
| 토큰 | `--background/--foreground/--card/--muted-foreground/--border/--ring` | 동일 이름으로 선언 |
| 라운드 | `--radius: 0.625rem` + sm/md/lg/xl 파생 | 6/8/10/14px |
| 그림자 | `shadow-xs`, `shadow-sm` | 기존 2겹 그림자를 훨씬 얕게 |
| 포커스 | `ring-[3px] ring-ring/50` | `:focus-visible`에 3px 링 |
| 타이포 | `tracking-tight`, `font-medium(500)/semibold(600)` | 기존 750~800 굵기를 500~600으로 |

### 컴포넌트 매핑
- `.nav .lvl` → **Tabs** (TabsList/TabsTrigger). 활성 탭 = primary 채움
- `.kpi`, `.card`, `.section`, `.intro` → **Card** (rounded-xl + border + shadow-xs)
- `.badge`, `.chip`, `.gtag`, `.hl-tag`, `.newsitem .b` → **Badge**
  - 가장 큰 변화: 알약(`border-radius:20px`) → `rounded-md(6px)`
- `.gchip` → **ToggleGroup**
- `.search` → **Input** (h-36, shadow-xs, 포커스 링)
- `.bigback`, `.nav .back` → **Button** (secondary / ghost)
- `.hint`, `.banner` → **Alert** (destructive / warning)
- `table` → **Table** (th height 40px, font-medium, muted-foreground)

## 유지한 것 (의도적 예외)
사용자가 여러 차례 직접 조정한 값은 shadcn 기본값보다 우선했다.

- **기준일 노란 배지** — 배경 `rgba(255,216,77,.26)`, 15px/600, `b`는 16px/700.
  중립 팔레트로 흡수하면 "언제 자료인지"가 묻힌다. 모서리·테두리만 shadcn화.
- **큰 뒤로가기 버튼** — Button secondary + size lg (h-46, 15px/600).
  기본 outline은 존재감이 너무 약했다.
- **클릭 안내(`.hint`)** — 15px/600 붉은 Alert 유지.
- **부문 색상** — 청과 주황 / 채소 녹색. neutral 팔레트에 맞춰 톤만 재조정
  (`#c2410c` / `#15803d`, 다크 `#fb923c` / `#4ade80`).

## 검증
- JS가 생성하는 클래스 66개 전부 CSS에 선언돼 있는지 정규식으로 대조 → 누락 0
- 외부에서 참조하는 CSS 변수 8개(`--up/--down/--flat/--ink/--line/--muted/--chae/--cheong`)
  는 레거시 별칭으로 유지 → 차트 SVG 코드 무수정
- 로컬 서버로 라이트/다크 × 드릴다운 3단계 렌더 확인
