## 호출 규약

BIX5 데이터소스는 세션 쿠키를 요구하고, 파라미터는 **POST 본문 최상위에 평문 JSON**으로 넣는다.

```
1) GET  https://db.garak.co.kr:9443/shares/{SHARE_ID}?defaultParameter={...}   → JSESSIONID 획득
2) GET  https://db.garak.co.kr:9443/api/dashboards/{SHARE_ID}                  → 세션 확정
3) POST https://db.garak.co.kr:9443/api/datasources/{DS_ID}?dummy={ms}
   Content-Type: application/json
   body: {"s_date":"20260821","s_unitcd":"t","handlClssCd":"2"}     ← 평문 최상위
   → {"dataset":[...]}
```

### 함정 세 가지

1. **세션 없이 호출하면 `rows=0`** — 조용히 빈 배열을 준다. 에러가 아니다.
2. **본문이 `{}` 면 날짜를 무시하고 낡은 스냅샷을 준다.** 가격 소스는 2026.08.03~08.08 고정,
   반입물량은 특정일 고정. 파라미터를 평문으로 넣어야 실제 날짜가 반영된다.
   `{"parameters":{...}}`, `{"params":{...}}`, `{"defaultParameter":{...}}` 는 모두 무시된다.
3. 휴장일은 전 품목 `TOT=0` 으로 나온다 (예: 2026-02-01 일요일).
